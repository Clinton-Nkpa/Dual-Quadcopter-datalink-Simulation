# Dual-Quadcopter-datalink-Simulation
I am developing a Linux-based simulation and visualization sandbox. My attached design brief describes two near-identical aircraft, each with a deterministic H743-class flight controller, IMU, four-motor/4-in-1 ESC powertrain, ELRS pilot link, and a Raspberry Pi companion for autonomy, telemetry, logging, and inter-aircraft coordination.
